# жИИзнь 2.0

Сайт онлайн-программы с интерактивным цифровым вступлением.

Статические HTML/CSS/JavaScript. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Вступление показывается при первом открытии во вкладке. Для повторного просмотра: `?intro=1`; чтобы сразу открыть программу: `#program`. Системное уменьшение движения поддерживается.
